# @artstesh/charts

Let's plot the data ;)

### Description of the project

The main purpose of the project is to make easier the process of creating of charts in Angular applications.

It's just the first, initial version of the library, that gonna become much more functional in a few weeks.

## Support status

This line is **archived**: its Angular major (14) left Angular's support window
(November 2023), so it receives no features, fixes, ports, or releases. The published npm
versions stay available:

```
npm install @artstesh/charts@3
```

npm serves this line under the `v3-latest` dist-tag. The actively maintained lines are
the newest ones in this repository; see the charts documentation for the support policy.
